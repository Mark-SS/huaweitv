# 开发文档 —— 答题看电视（QuizTV）

安装与使用请看仓库根目录 [README.md](../README.md)，这里只记录构建、代码结构与题库格式。

看电视时每隔 **10 分钟**（可调 1–120 分钟）全屏弹出一道**小学四年级**题目：

- 答对 → 题目消失，继续看电视，重新计时；
- 答错 → **再加一题**（需要连续答对的题数 +1），并显示正确答案和解析；
- 弹题期间遥控器的返回/菜单键无效，只能答题或输入家长密码退出；
- 弹题时自动请求音频焦点并发送“暂停”键，让正在播放的视频暂停（可关闭）；
- 开机自启，后台常驻（前台服务），可选无障碍/通知监听“复活钩子”防止被系统清理；
- **不 root、不动系统应用、不改桌面**；安装前自动备份电视状态，`restore.sh` 一键还原。

## 题目范围（人教版/部编版四年级）

| 类别 | 形式 | 内容 |
| --- | --- | --- |
| 数学 | 程序随机生成，永不重复 | 三位数乘两位数、除数是两位数的除法（含余数）、四则混合运算、大数的认识（数位、四舍五入到万位）、小数点移动、小数加减、单位换算（千米/吨/公顷/平方千米/时分）、角的分类、三角形内角和与三边关系、鸡兔同笼、植树问题、平均数、积的变化规律、速度时间路程 |
| 语文 | 静态题库 | 四年级上下册古诗、课文作者与内容、神话寓言、成语填空、近反义词、修辞手法、字词辨析 |
| 英语 | 静态题库 | PEP 四年级单词与句型（学校场所、时间、天气、农场动物、衣物、三餐、数字） |
| 科学/常识 | 静态题库 | 声音、呼吸消化、电路导体、种子萌发、天文地理、节气、地理常识 |

静态题库在 `../app/src/main/assets/questions.json`，格式：

```json
{"c":"语文","q":"题干","o":["正确答案","干扰项1","干扰项2","干扰项3"],"a":0,"e":"解析"}
```

正确答案放第一个即可（`a:0`），程序出题时会自动打乱选项顺序。直接往文件里追加即可扩充题库。

## 构建

项目为纯 Java、零第三方依赖的 Android TV 应用（minSdk 24）。

```bash
./gradlew assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk（已用 debug 签名，可直接安装）
```

## 家长设置

- 默认家长密码 **1234**，首次使用请在 App 内「修改家长密码」。
- 修改间隔、关闭功能、修改密码都需要先输入家长密码。
- 弹题界面右下角「家长模式」输入密码可临时跳过本次答题。
- 首页显示今日答题数、答对数和正确率。

## 代码结构

```
app/src/main/java/com/quiztv/guard/
├── MainActivity.java    设置界面（遥控器可操作）
├── GuardService.java    前台服务：计时、弹题、暂停/恢复播放、开机自启
├── QuizOverlay.java     全屏答题悬浮窗，“答错再加一题”逻辑
├── QuizRootLayout.java  拦截返回键，支持遥控器数字键 1-4 直接作答
├── KeepAliveService.java 可选无障碍“复活钩子”，被系统重新绑定时拉起守护服务
├── RevivalListener.java  可选通知监听“复活钩子”，同上
├── QuestionBank.java    题库：50% 随机数学 + 50% 静态题库，自动打乱选项
├── MathGenerator.java   四年级数学随机出题器（17 类题型）
├── Question.java        题目模型
├── Prefs.java           设置与统计持久化
└── BootReceiver.java    开机自启

scripts/
├── install.sh   备份 -> 安装 -> 授权 -> 启动 -> 验收
├── backup.sh    备份电视状态到 backups/<时间戳>/
├── restore.sh   按备份一键还原
├── verify.sh    验收
└── common.sh    公共函数（连接、adb 封装）
```
